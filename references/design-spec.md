# 欢语派对活动 H5 美术设计规范

> 本规范从「情人节、星河蜜语、星河赴约、贵族幸运周、心愿水晶球、寿星请就位、魔法学院、马上有财、双十一、超级电音节、返场礼物」共 163 张已上线活动设计稿中蒸馏而成。
> 核心结论：**统一组件骨架 + 主题化皮肤**。弹窗、按钮、卡片、榜单、进度条、tab 的形态跨主题不变；只有配色、字体风格、装饰母题随主题切换。

---

## 一、通用设计骨架（跨主题不变）

### 1.1 布局结构
- 手机竖屏 375px 逻辑宽度画板，垂直结构：**Hero 区（25%–40% 屏高）→ 胶囊 Tab → 主功能面板（60% 屏高，可滚动）→ 底部固定 CTA**。
- Hero 区：主题插画 + 艺术字大标题压在插画上，规则/记录入口常悬浮于右上角。
- 模块之间用「丝带标题 / 花瓣分隔 / 金线」分隔，**禁止硬分割线和直角**。
- 装饰元素（花、星、光斑、爱心）放四角与边缘，半透明，不遮挡内容。
- 弹窗遮罩：黑色 40%–60%，弹窗宽约 90% 屏宽居中；关闭按钮为「白描边圆 + ✕」，固定在弹窗外底部中央。

### 1.2 组件形态（所有主题通用）
| 组件 | 形态规范 |
|---|---|
| 主按钮 CTA | 胶囊形（圆角=高度一半），渐变填充，2px 白描边，顶部高光带，外发光，文字白色加粗 |
| 次按钮 | 半透明白/浅灰渐变底 + 主题色描边 + 主题色文字 |
| 双按钮弹窗 | 左「取消」（灰或描边态）+ 右「确认」（主题渐变），等宽并排 gap 8px |
| Tab 胶囊组 | 横排胶囊；激活态=主题渐变实底+白字+外发光；未激活=半透明玻璃底+浅色字 |
| 卡片 | 大圆角 12–24px，渐变面板，1–2px 白/金色细描边，顶部内高光 |
| 榜单条目 | 白/浅色圆角横卡：左头像（金/银/铜冠饰，Top1 更大居中突出）+ 中昵称数值 + 右排名徽章 |
| 进度条 | 胶囊轨道（半透明底），填充为主题强调色渐变，可带分段节点与奖励图标，数值加粗亮色 |
| 徽标/角标 | 小圆角标签（如「90天」「永久」「VIP」），高饱和粉/金/紫，置于奖励图右上角或卡片顶部 |
| 状态徽章 | 「已领取」=亮色渐变底；「未领取」=灰紫底；「已获得」=深绿/亮绿 |
| 弹窗 | 三段式：异形标题条（丝带/珠链/宝石装饰）+ 内容区 + 底部按钮；圆角 20–28px |
| 缺省态 | 面板保留，内容居中放半透明插画图标 +「暂无记录~」浅色文字，无操作按钮 |
| 数量步进器 | 胶囊，「−」数字「+」，主题描边 |

### 1.3 状态体系（必须逐个落实）
| 状态 | 视觉处理 |
|---|---|
| 默认 | 主题渐变 + 白描边 + 顶部高光 + 外发光 |
| 按下 | 加深 10%–15%，高光下移，可轻微 scale(0.97) |
| 完成/已通关 | 暖橙金渐变（#FFB46A→#FF9550 系）或金色高亮 |
| 已领取/已签到 | 绿色系（#97C459 描边文字 / #EAF3DE 底）或金粉渐变 |
| 禁用/售罄 | 去饱和银灰紫（#C9C2D8→#8A82A0），60% 透明白蒙版，无发光，cursor:default |
| 选中 | 实底渐变 + 白字 + 外发光；未选中为玻璃半透 |
| 锁定/未解锁 | 内容降亮 40% + 居中锁形图标 + 紫色半透蒙版 |
| 红点提醒 | #FF5A5A 圆点，置于 tab/按钮右上角 |

### 1.4 艺术字与文字层级
- **标题艺术字**：渐变填充（主题色系）+ 2–4px 白色描边（-webkit-text-stroke 或多重 text-shadow）+ 主题色外发光（text-shadow 模糊光晕）+ 对称装饰（翅膀/花/星，可用 ✦ ❀ ♥ 👑 等 Unicode 或 CSS 伪元素近似）。
- **关键数字**（积分/倒计时/名次）：亮色加粗（金 #FFD24A 或主题强调色），可带发光。
- **字号层级**：Hero 大标题 26–34px → 栏目标题 16–18px → 按钮 13–15px → 正文 12–14px → 辅助 10–11px。
- 字体栈：`"PingFang SC","Microsoft YaHei",sans-serif`，标题可用 `font-weight:800` + `letter-spacing:1~2px` 近似艺术字。

### 1.5 CSS 高保真质感手法（纯代码逼近设计稿）
- 渐变面板：`linear-gradient(180deg, 亮色, 深色)` + `border:1.5~2px solid rgba(255,255,255,.8)` + `box-shadow: 0 0 18px 主题光色, inset 0 2px 6px rgba(255,255,255,.6)`。
- 顶部高光带：`::before` 半透明白色胶囊覆盖按钮/卡片顶部 40% 高度。
- 玻璃质感：`background:rgba(255,255,255,.14)` + `backdrop-filter:blur(6px)`。
- 星点/光斑氛围：容器 `::after` 用多组 radial-gradient 小圆点铺满，或少量 ✦ 字符绝对定位。
- 深色背景上的粒子星空：多层 radial-gradient 背景叠加。
- 禁止：纯色直角块、硬黑阴影（用主题色光晕代替）、系统默认按钮样式。

## 二、默认主题皮肤：梦幻紫粉（品牌主调）

> 情人节 / 星河赴约 / 贵族幸运周 / 心愿水晶球 / 寿星请就位 的公共基调，未指定主题时一律用这套。

### 2.1 色板
| 角色 | 值 |
|---|---|
| 页面背景（深空） | `linear-gradient(180deg,#15123E 0%,#2A1B5C 55%,#4B2A8A 100%)` + 星点粒子；亮色变体：`linear-gradient(180deg,#F9C4D6,#E6E9FF)` |
| 主面板 | `linear-gradient(180deg,#FBD3EC 0%,#C7A6E8 55%,#9B7BD4 100%)`；浅色卡片：`linear-gradient(180deg,#FFFFFF,#F5E8FF)` |
| CTA 主按钮 | `linear-gradient(90deg,#FF6FA8,#FF8C7A)` 白描边 2px，外发光 `0 0 14px rgba(255,111,168,.6)` |
| 次按钮（紫） | `linear-gradient(90deg,#A89DE8,#7E8CE8)` |
| 橙金按钮（兑换/抽奖类） | `linear-gradient(90deg,#FFAE4D,#F97B30)` |
| 强调色 | 金 `#FFD24A`、亮粉 `#FF4D7E`、冰青 `#5BDEF5`、皇家金 `#F0C34E` |
| 文字 | 标题白（粉紫描边）；正文深紫 `#4A2E7A`；辅助 `#8E7AB8`；链接/状态 `#FF6FA8` |
| 金属三色（榜单） | 金 `#FFD56B` / 银 `#E8E9F0` / 铜 `#CD8C52` |

### 2.2 装饰母题
星点粒子、月亮、玫瑰、爱心、翅膀、钻石、缎带丝带、珠链、光斑、樱花。弹窗顶部中央放「宝石+丝带」装饰，标题两侧配对称小装饰。
